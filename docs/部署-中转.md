# 中转部署（Bot 在服务器，玩家在各地）

适合把 Bot 放在云服务器、玩家从自己电脑连过来的场景。

```
玩家 Minecraft ──ws/http──> 公网 relay:18574 ──> 127.0.0.1:3001/3000 (NapCat) ──> QQ
```

NapCat 不暴露公网，只暴露 relay 一个端口。

## 1. 服务器准备

- Windows Server 2019/2022（Desktop Experience）或 Windows 10/11
- QQ NT + NapCat Shell
- 编译 `relay/` 得到 `QQRelay.exe`

## 2. 启动 NapCat

用本地模式那套启动器启动并登录，确认：
`napcat/config/onebot11_<QQ>.json` 里 HTTP 3000、WS 3001，host 为 127.0.0.1。

## 3. 配置 relay

把 `QQRelay.exe`、`relay.ini`、`start-relay.cmd` 放同一目录。

`relay.ini`：

```ini
listenHost=+
listenPort=18574
napcatWs=ws://127.0.0.1:3001
napcatHttp=http://127.0.0.1:3000
token=这里填32位以上随机串
allowIps=
maxClients=64
ratePerMinute=120
```

生成 Token：

```powershell
[guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
```

## 4. 放行端口

- 云控制台安全组：只放行 relay 端口（TCP 18574）
- 不要放行 3000/3001/6099
- RDP 端口如果也暴露，建议限制来源 IP

启动：

```bat
start-relay.cmd
```

首次会自动 `netsh http add urlacl`。日志在 `relay.log`。

## 5. 让模组走中转

### 方式 A：启动器

启动器 → 管理员设置 → “服务器中转”：

- 地址：`公网IP:外部端口`（如 1.2.3.4:28574）
- Token：留空会自动生成，或填 relay.ini 里的 token
- 启动机器人时启动器会自动写 relay.ini 并拉起 QQRelay.exe，停止时一起关闭

保存后模组配置自动变成：

```json
"wsUrl": "ws://公网IP:18574/ws",
"httpUrl": "http://公网IP:18574/api",
"token": "<relay token>"
```

### 方式 B：手动改配置

把 `docs/配置示例-中转.json` 复制到 `.minecraft/config/qqchatbridge.json`，
替换 `RELAY_HOST`、`RELAY_TOKEN`、`RELAY_GROUP_ID`。

## 6. 客户端

玩家只需要：

- 用户版 jar + Fabric API + converse + yacl
- 上面那份 `qqchatbridge.json`

不需要 NapCat，也不需要启动器。

## 7. 隐私与防扫描

- relay 只响应 `/ws`、`/api/*`，其它 404；无 Token 401；超频 429
- 固定玩家出口 IP 时填 `allowIps`
- Token 泄露后同时改 relay.ini 和所有客户端配置
- 生产环境建议 TLS 终止：Caddy/Nginx 反代到 `127.0.0.1:18574`，
  客户端用 `wss://`/`https://`（模组当前按配置字符串连接，支持 https/wss）
- 不要用 80/443/3389 作为 relay 端口

## 8. 已知限制

- 文字、图片、表情、`/qq say` 走中转没问题
- 语音播放依赖 `get_record` 返回的服务器本地文件，纯中转模式取不到；
  需要语音时让客户端与 NapCat 同机/局域网，或后续给 relay 增加媒体代理
- relay 不内置 TLS，公网请前置反向代理
## 9. 下发配置（统一改连接地址）

- 启动器启用中转并启动机器人后，会在 `relay\` 生成：
  - `client-config.json`（共享配置，relay 的 `/client-config` 会读取它）
  - `client-bootstrap.json`（给玩家用的引导配置，含 remoteConfigUrl / remoteConfigToken）
- 玩家端配置里只要有：

```json
"remoteConfigUrl": "http://公网IP:外部端口/client-config",
"remoteConfigToken": "<relay token>"
```

模组启动或进世界时会自动拉取共享配置，覆盖 ws/http/token/群号/多群规则/模板等。

- 管理员改完设置 → 重启机器人（重写 client-config.json）→ 玩家重进世界生效
- 用户端没有写接口、没有 push 指令，只能读
- `/client-config` 同样要求 Bearer Token；没有 Token 返回 401
