# 本地部署（NapCat 与游戏在同一台机器）

适合单机/自己电脑玩。

## 1. 准备

- Minecraft 26.2 + Fabric Loader 0.20.1+ + Java 25
- QQ NT 9.9.x（Windows 10 1809+）
- NapCat Shell：https://github.com/NapNeko/NapCatQQ/releases
- 本仓库编译出的启动器

## 2. 目录

```
QQBridge/
├─ QQBot启动器.exe
├─ napcat/                  NapCat Shell 解压到这里
├─ mods/                    qqchatbridge-1.0.0.jar、fabric-api、converse、yacl
└─ config/converse/image.json
```

## 3. 启动机器人

1. 右键管理员运行 `QQBot启动器.exe`
2. 填机器人 QQ 号
3. 点“启动机器人”
4. 扫码登录
5. 登录成功后自动弹“选择群”，选目标群（群号写入模组配置）

启动器会自动生成 Token 并写入：

- `napcat/config/onebot11_<QQ>.json`
- `napcat/config/onebot11.json`
- `napcat/config/webui.json`
- `.minecraft/config/qqchatbridge.json`

## 4. 安装模组

启动器“安装模组到 mods”选择 `.minecraft/mods`，或手动复制：

- `qqchatbridge-1.0.0.jar`
- `fabric-api-*.jar`
- `converse-*.jar`
- `yet_another_config_lib_v3-*.jar`

## 5. 验证

进游戏：

```
/qq status
```

看到“已连接”、群号正确即可。群里发消息应出现在聊天栏；
游戏里 `:测试` 应发到 QQ 群。

## 6. 常见问题

- 启动器找不到 QQ.exe：点“自动查找”
- 注入失败：完全退出 QQ 再启动
- 消息不同步：看 `/qq status` 的帧数/消息事件/丢弃计数
