# 构建管理员版

用户版与管理员版共用同一套源码，差异只有三处：

## 1. 打开管理员标记

`mod/src/main/java/com/qqchatbridge/Edition.java`：

```java
public static boolean isAdmin() {
    return true;   // 用户版是 false
}
```

## 2. 恢复管理员指令

在 `mod/src/main/java/com/qqchatbridge/command/QqCommand.java` 的指令树里补回：

```java
.then(ClientCommands.literal("reload")
        .executes(context -> reload(context.getSource())))
.then(ClientCommands.literal("broadcast")
        .then(ClientCommands.argument("enabled", BoolArgumentType.bool())
                .executes(context -> setBroadcast(context.getSource(),
                        BoolArgumentType.getBool(context, "enabled")))))
.then(ClientCommands.literal("group")
        .executes(context -> showGroup(context.getSource()))
        .then(ClientCommands.literal("off")
                .executes(context -> clearGroup(context.getSource())))
        .then(ClientCommands.argument("id", LongArgumentType.longArg(1L))
                .executes(context -> setGroup(context.getSource(),
                        LongArgumentType.getLong(context, "id")))))
```

并补回 `reload` / `setBroadcast` / `setGroup` / `clearGroup` 四个方法
（实现见 git 历史或按用户版 `showGroup` 的写法补）。

需要 import：

```java
import com.mojang.brigadier.arguments.BoolArgumentType;
```

## 3. 改 mod 元数据

`mod/src/main/resources/fabric.mod.json`：

```json
"id": "qqchatbridge_admin",
"name": "QQ Chat Bridge Admin"
```

`mod/gradle.properties`：

```properties
archives_base_name=qqchatbridge-admin
```

## 构建

```bash
cd mod
./gradlew build
# 产物：build/libs/qqchatbridge-admin-1.0.0.jar
```

两个版本**二选一安装**，不要同时放进 mods。
